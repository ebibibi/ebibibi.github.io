YouTube Live の配信中に、自己紹介ページに **ブログ機能** を追加しました。
この記事がその最初の投稿です。記念に残しておきます。

## 仕組み

このブログは [Jekyll](https://jekyllrb.com/)（GitHub Pages 標準の仕組み）で動いています。

- 記事は Markdown で書く
- `_posts/` に置いて push するだけで自動で HTML 化される
- ブログ一覧やトップページにも自動で並ぶ

## 新しい記事の書き方

`_posts/` フォルダに `YYYY-MM-DD-タイトル.md` という名前でファイルを作り、
先頭に次のように書きます。

```markdown
---
title: 記事のタイトル
---

ここに本文を Markdown で書く。
```

あとは GitHub に push すれば、数十秒後に公開されます。

それでは、これからよろしくお願いします。
